# RealEarth — что возможно, что невозможно, и почему

Документ честный. Прочитай его до того, как ждать готовый мир.

## 1. Жёсткие ограничения движка Minecraft 1.21.1 (изменить нельзя)

| Требование | Лимит движка | Что делаем |
|---|---|---|
| Высота мира до -10000 | `height` измерения ≤ **4064**, `max_y` ≤ **2032**, оба кратны 16 | min_y = **-2032**, max_y = **2032**. Глубже физически некуда. |
| Океаны реальной глубины (Марианская −10 935 м) | см. выше | Нелинейное сжатие батиметрии: **1:1 до −1000** (как ты и просил), ниже — логарифмическое сжатие −1000…−11000 в −1000…−2032 |
| Горы 1:1 (Эверест 8849 м) | max_y 2032 | 1:1 до **+1500**, выше — сжатие 1500…8849 в 1500…2000. Сжатие настраивается **по регионам**: Непал/Кавказ/Альпы получают мягкую кривую, равнины — чистый 1:1 |
| Мир 1:1 по горизонтали | координаты ±29 999 984 | Экватор 40 075 км = 40 075 000 блоков — **влезает**. Оба масштаба (1:1 и 1:2) поддержаны, по умолчанию 1:2 |
| «Грузится только до −64, глубже — по мере спуска» | чанк в MC — **цельная колонна**, секции отправляются пакетом целиком | Частично: отложенная генерация глубоких секций + интеграция с Voxy/DH для LOD. Это самая рискованная часть, см. `docs/40-streaming.md` |
| Отдельный мод «делит нагрузку CPU↔GPU» | Java-мод не может вынести чанкген на GPU без нативного слоя; на выделенном сервере GL-контекста нет вообще | Реально выносится **один этап** — сэмплинг шума/климата через OpenGL compute shader на клиенте, с CPU-фоллбеком. Всё остальное — многопоточность, а не GPU |

## 2. Что делается честно и полностью

- Геоданные из открытых источников (GEBCO 2024 — батиметрия+рельеф, Köppen-Geiger — климат, Natural Earth — береговые линии/реки, WorldClim — осадки/температура)
- Ручное добавление источников: `config/realearth/sources.json`
- Генератор мира по этим данным, 1:1 / 1:2, сжатие высот по кривой
- Климатический движок: сетка, циклоны с адвекцией и затуханием, осадки по биому, часовые пояса, сезонный лёд/паводки
- Залежи (Кузбасс, Донбасс, нефть) по реальным координатам — поверх ванильной генерации руд, Create Aeronautics не ломается
- HUD-инфо по региону
- Спавн фауны по ареалу
- Выветривание блоков по влажности
- Закольцованность по долготе (восток↔запад) — географически корректно. Север↔юг закольцевать нельзя, там полюса

## 3. Что НЕ будет сделано в этой итерации

- Космос/орбита — только заготовка рендера, потолок 2032 м не даёт настоящей орбиты
- Объёмные грозовые фронты-тучи — нужен свой рендер облаков, это отдельный большой кусок
- GPU-оффлоад — заготовка compute shader, без него работает на CPU
