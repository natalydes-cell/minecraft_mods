# RealEarth — NeoForge 1.21.1

Реальная Земля в Minecraft: рельеф и батиметрия из открытых геоданных, климат по Кёппену,
движущиеся циклоны, реальные залежи, закольцованность по долготе.

**Прочитай сначала [`docs/00-SCOPE-RU.md`](docs/00-SCOPE-RU.md)** — там честно расписано, какие из
твоих требований движок Minecraft выполнить не даёт и что сделано вместо них.

### Баги, найденные и исправленные тестами

1. **`reliefBoost` зависел от наклона склона** → одна высота давала разный Y → искусственные
   обрывы на каждом перегибе рельефа. Теперь функция только от высоты; монотонность проверена
   на всём диапазоне −10935…+8849 м, инверсий ноль.
2. **Высотная поправка температуры считалась дважды** (класс Кёппена уже включает высоту).
   Эверест выходил −69.7 °C вместо примерно −20. Теперь поправка только к превышению над
   окрестным рельефом → −35.9 °C.
3. Уровень облаков в мороз уходил ниже уровня моря.
4. `doFill` писал блоки поштучно вопреки собственному javadoc. Переписан на посекционную
   запись под одним acquire/release.

### Команда `/realearth`

```
/realearth here                  что подо мной
/realearth probe <шир> <долг>    что в любой точке Земли, не летая туда
/realearth goto <шир> <долг>     телепорт по координатам (нужен OP)
/realearth storms                активные циклоны планеты
```

`probe` отвечает и для тех мест, куда рельеф ещё не импортирован.

### Баги, найденные и исправленные тестами

1. **`reliefBoost` зависел от наклона склона** → одна высота давала разный Y → искусственные
   обрывы на каждом перегибе. Теперь функция только от высоты; монотонность проверена на
   всём диапазоне −10935…+8849 м.
2. **Высотная поправка температуры считалась дважды** (класс Кёппена уже включает высоту).
   Эверест выходил −69.7 °C вместо примерно −20.
3. Уровень облаков в мороз уходил ниже уровня моря.
4. `doFill` писал блоки поштучно вопреки собственному javadoc.
5. **WorldClim «10m» — это 10 угловых минут** (6 сэмплов на градус), а не 10 на градус.
   Поймала проверка размеров растра.
6. **38 месторождений вообще не размещались** — `DepositRegistry` был таблицей, которую никто
   не читал. Добавлен `DepositPlacer`.
7. **`sources.json` не перезаписывался при обновлении мода.** Файл оставался с первого запуска,
   с `samplesPerDegree: 60` вместо 120, и мод читал климат в половинном разрешении: Кузбасс
   определялся как EF_ICE_CAP, Гхавар как DFC_SUBARCTIC. Добавлен `formatVersion`: устаревший
   файл отодвигается в `sources.json.old` с громким предупреждением.
8. **Верификатор проверял не то.** Он брал параметры из кода, а не из `sources.json`, который
   реально читает мод — поэтому и проходил, пока игра была неправа. Теперь читает тот же файл.

## Сборка

Нужен **JDK 21**. Поставь Temurin 21:

```bash
winget install EclipseAdoptium.Temurin.21.JDK
```

Затем из папки проекта:

```bash
gradle wrapper --gradle-version 8.10
```

```bash
./gradlew build
```

Готовый `.jar` окажется в `build/libs/realearth-0.1.0-mc1.21.1.jar`.

Первая сборка скачает NeoForge и распакует Minecraft — это 10–20 минут и несколько гигабайт.

## Геоданные

При первом запуске мод создаёт `config/realearth/sources.json` со списком источников.
Правь его как хочешь: можно подменить URL на свой мирор, подставить региональный LIDAR
высокого разрешения или вообще убрать URL и положить тайлы руками в
`config/realearth/data/<источник>/`.

Формат тайлов на диске — сырой `<tx>_<ty>.r16` (little-endian int16). GeoTIFF и PNG
намеренно не читаются в рантайме: их декодирование на потоках генерации чанков дороже
самой генерации.

## Мультиплеер

Вся симуляция — серверная. Клиент получает список циклонов и интерполирует между пакетами,
поэтому шторм у всех игроков в одном месте. `SolarTime` не меняет мировое время, а выводит
местное из него, так что редстоун и другие моды продолжают работать.
