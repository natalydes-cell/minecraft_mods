RealEarth — реальная Земля в Minecraft
NeoForge 1.21.1
================================================================================

ЧТО В ПАПКЕ

  mods/      — сам мод, один .jar
  config/    — настройки и геоданные (уже импортированы, 21 МБ)
  tools/     — импортёр, чтобы докачать другие регионы
  docs/      — что работает, что нет и почему


================================================================================
УСТАНОВКА
================================================================================

1. Поставь NeoForge 1.21.1 (версия 21.1.209 или новее).

2. Скопируй папки mods и config в свою папку Minecraft:

     Windows:  %APPDATA%\.minecraft\
     Сервер:   в корень папки сервера

   Если такие папки уже есть — просто слей содержимое, ничего не удаляя.

3. Создай НОВЫЙ мир. Существующий не подойдёт: мод меняет высоту измерения
   с -64..320 на -2032..2032, и старые чанки в него не лягут.

4. Выдели Java хотя бы 6 ГБ. Мир в двадцать миллионов блоков шириной —
   это не ванильный мир.


================================================================================
ЧТО УЖЕ ЕСТЬ В ДАННЫХ
================================================================================

  Климат (Köppen)    — вся планета, 1 км
  Температуры        — вся планета
  Осадки             — вся планета
  Геология           — вся планета (тип породы для пещер)
  РЕЛЬЕФ             — ТОЛЬКО НЕПАЛ (27-30° с.ш., 85-88° в.д.)

Рельеф импортирован только для Непала, потому что вся планета — это 6 ГБ
скачивания и несколько часов. Везде за пределами Непала земля будет
ПЛОСКОЙ равниной, пока ты не импортируешь нужный регион.


================================================================================
СОПУТСТВУЮЩИЕ МОДЫ (по желанию)
================================================================================

Из папки tools:

  get-mods.bat

Скачает четыре мода с официального сайта Modrinth, версии закреплены, каждый
файл проверяется по контрольной сумме. Повторный запуск ничего не перекачивает.

  Better Clouds     объёмные тучи, которые идут за реальной погодой
  YACL              обязателен для Better Clouds, без него тот не загрузится
  Cold Sweat        температура тела по реальному климату
  Distant Horizons  рельеф Земли до самого горизонта

Все четыре НЕОБЯЗАТЕЛЬНЫ — мод работает и без них.

Better Clouds, YACL и Distant Horizons клиентские: серверу они не нужны, и
игроки без них смогут зайти.

Сами jar в этот архив не вложены намеренно: это чужие моды под копилефт-
лицензиями, и качать их из первоисточника правильнее, чем раздавать копии.

Чтобы тучи были огромными, подними в настройках Better Clouds:
Distance 4 -> 8, Size XZ 16 -> 28, Size Y 8 -> 20, пресет шума -> Grand.
Подробности в docs/30-CLOUDS-RU.md


================================================================================
КАК ДОБАВИТЬ СВОЙ РЕГИОН
================================================================================

Нужна Java 21 в PATH. Из папки tools:

  import-region.bat 35 72 -12 45      — Европа
  import-region.bat 41 82 19 180      — Россия
  import-region.bat 15 72 -170 -52    — Северная Америка
  import-region.bat -56 13 -82 -34    — Южная Америка
  import-region.bat -35 38 -18 52     — Африка
  import-region.bat -44 -10 112 154   — Австралия
  import-region.bat -90 -60 -180 180  — Антарктида

Порядок аргументов: минШирота макШирота минДолгота макДолгота.
Южная широта и западная долгота — со знаком минус.

Вся планета целиком (около 6 ГБ, несколько часов):

  import-world.bat

Прервалось — просто запусти снова, скачанное не потеряется.

На Linux и macOS вместо .bat используй import-region.sh


================================================================================
КУДА СМОТРЕТЬ В ИГРЕ
================================================================================

Координаты Minecraft при масштабе 1:2 (по умолчанию):

  X = долгота / 180 * 10018754
  Z = -широта / 90 * 5000983

Готовые точки для /tp (посчитаны, а не прикинуты):

  Эверест           /tp @s 4838223 1950 -1555200
  Лхоцзе            /tp @s 4838669 1900 -1553733
  Катманду          /tp @s 4749112 1400 -1540147
  Тибетское плато   /tp @s 4814568 1700 -1639211

Ставь себя в креатив и включай полёт перед телепортом: на такой высоте
под тобой может не оказаться земли, пока чанк не догрузится.

В правом верхнем углу мод показывает координаты, высоту, температуру
и местное время. При входе на новую территорию всплывает карточка с названием.


================================================================================
НАСТРОЙКА
================================================================================

config/realearth.toml — там всё с пояснениями. Главное:

  metresPerBlock = 2.0        масштаб. 1.0 = 1:1, но чанков вчетверо больше
  emptyRegionUnloadSeconds    первое, что стоит уменьшить, если сервер тормозит
  tileCacheSize               второе, если не хватает памяти
  enableCyclones = true       движущаяся погода
  daysPerYear = 96            длина года: влияет на сезоны и лёд

config/realearth/sources.json — откуда берутся данные. Можно подменить на
свои источники, например национальный LIDAR вместо ETOPO для одной страны.

config/realearth/regions.json — названия территорий для карточки. 76 штук,
можно дописывать свои.


================================================================================
ЧЕСТНО О ГРАНИЦАХ
================================================================================

  Глубина -10000 невозможна. Предел движка Minecraft — 4064 блока высоты,
  то есть -2032..2032. Масштаб 1:1 держится от -1000 до +1500 м (как просил),
  дальше идёт сжатие.

  Эверест будет на высоте y=1914, а не 8849. Две причины: потолок движка и
  то, что в исходных данных 15" самой вершины нет — ячейка 460 м хранит
  среднее по ячейке. Подробный разбор в docs/10-DATA-RU.md.

  Вертикальная подгрузка «сначала до -64, потом глубже» не сделана. Чанк в
  Minecraft — цельная колонна, половину секций клиенту не отправить.

  Не сделано: интеграции Cold Sweat / Voxy / Create, паводки, морской лёд,
  объёмные тучи, космос, перенос нагрузки на GPU.

  Полный список — в docs/00-SCOPE-RU.md.
