# minecraft_mods

## RealEarth — реальная Земля в Minecraft

NeoForge 1.21.1. Рельеф и батиметрия из открытых геоданных, климат по Кёппену, движущиеся
циклоны, реальные месторождения, часовые пояса, закольцованность мира по долготе.

### Быстрый старт

1. Скачай [`RealEarth/release/RealEarth-Release.zip`](RealEarth/release/) — 21.6 МБ, там всё.
2. Распакуй. Внутри `mods/` и `config/` — скопируй обе папки в `%APPDATA%\.minecraft\`
   или в корень сервера.
3. Поставь NeoForge 1.21.1 (21.1.209+), выдели Java от 6 ГБ.
4. Создай **новый** мир. Старый не подойдёт: измерение стало −2032…2032 вместо −64…320.

Полная инструкция — в `ПРОЧТИ-МЕНЯ.txt` внутри архива.

### Что внутри архива

| Данные | Покрытие |
|---|---|
| Климат (Köppen-Geiger, 1 км) | вся планета |
| Температуры и осадки (WorldClim) | вся планета |
| Геология (GLiM) | вся планета |
| **Рельеф (ETOPO 2022, 15″)** | **только Непал** |

Рельеф для остальных регионов докачивается импортёром — вся планета это 6 ГБ и несколько
часов, поэтому в архив она не вошла:

```
cd tools
import-region.bat 35 72 -12 45      # Европа
import-region.bat 41 82 19 180      # Россия
import-world.bat                    # вся планета
```

### Проверка на месте

```
/realearth probe 54.0 86.5     что в Кузбассе, не летая туда
/realearth here                что подо мной
/realearth goto 27.99 86.93    телепорт на Эверест
/realearth storms              активные циклоны планеты
```

### Интеграции

| Мод | Статус |
|---|---|
| **Cold Sweat** | сделано — мировая температура берётся из реального климата, а не из биома |
| **Distant Horizons** | работает без кода совместимости |
| **Create** | ванильная генерация руд не тронута |
| **Voxy** | **невозможно** — под NeoForge 1.21.1 не существует, только Fabric |

### Честно о границах

- **Глубина −10000 невозможна.** Предел движка Minecraft — 4064 блока высоты. Масштаб 1:1
  держится от −1000 до +1500 м, дальше сжатие.
- **Эверест будет на y≈1914, а не 8849.** Потолок движка плюс то, что в исходных данных 15″
  самой вершины нет: ячейка 460 м хранит среднее, а не пик.
- **Нефти в ваниле нет.** Никель, олово, бокситы и уран подхватываются по тегу
  `c:ores/<материал>` из любого рудного мода. Нефть — жидкость, а не руда, тега для неё не
  существует, поэтому в `deposit-blocks.json` лежат конкретные id (TFMG, Immersive Petroleum,
  PneumaticCraft). Если не подошёл ни один, `/realearth probe` честно напишет
  `[NO BLOCK CONFIGURED]`, а не сделает вид.
- **Перенос нагрузки на GPU — измерено и отклонено.** `gradlew benchmarkTerrain` даёт
  123.7 мкс на чанк, одно ядро тянет 8 082 чанка/с, пул из 10 потоков — около 80 000.
  Игроку нужно 50–200. Выборка рельефа быстрее необходимого в тысячу раз; на чанк приходится
  289 выборок, и загрузка задания на видеокарту заняла бы больше, чем сам расчёт.
- **Свой рендер объёмных облаков** — отказ осознанный: подмена облачного слоя ломает Iris и
  Sodium. Буря выражена через туман, цвет неба и предупреждение HUD.
- **Вертикальный стриминг чанков** — невозможен, чанк это цельная колонна.

Подробности — [`00-SCOPE-RU.md`](RealEarth/docs/00-SCOPE-RU.md) (границы движка),
[`10-DATA-RU.md`](RealEarth/docs/10-DATA-RU.md) (источники и точность) и
[`20-COMPAT-RU.md`](RealEarth/docs/20-COMPAT-RU.md) (интеграции и разбор про GPU).

### Сборка из исходников

Нужен JDK 21.

```
cd RealEarth
gradlew build           # мод -> build/libs/
gradlew importerJar     # импортёр -> build/tools/
gradlew exportRelease   # готовая папка -> build/RealEarth-Release/
gradlew verifyGeodata   # сверка импорта с геодезическими отметками
```
